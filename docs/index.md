# Analysis of AI’s Effect on Unemployment

By Max Leikas, Joonas Coatanea and Juha Salo

This project examines whether increasing AI adoption in Finnish
enterprises is associated with changes in unemployment. We compare
occupational groups and examine historical unemployment patterns.
